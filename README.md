# GAIA SLIME FUTSAL

가이아 시티 세계관의 5:5 슬라임 풋살 게임. **성인 시트콤 세계관과 직접 조작하는 풋살**을 함께 설계합니다.

> **중요:** 이 저장소 초기 패키지는 **v0.5.2 테스트 HTML을 변경 없이 보존**하고, 이후 코딩 전에 반드시 확인할 **결정/기획/작업기록 MD**를 포함합니다. **새로운 도파민, 얼굴, 인원 변경, 이벤트 시스템이 구현되었다는 뜻이 아닙니다.**

## 실행

- `index.html`을 브라우저로 열거나 GitHub Pages에서 실행합니다.
- 가로 화면 5대5, 조이스틱/패스/슛/대시/교체가 있는 현재 테스트 기준본입니다.
- 원본 스냅샷은 `baseline/SLIME_FUTSAL_v052.html`. **수정하지 않습니다.**

## 현재 v0.5.2와 최종 구상 차이

| 요소 | 현재 코드 | 신규 기획 |
|---|---|---|
| 팀 색 | 핑크 vs 민트 | 정규 리그는 **여성 핑크 vs 핑크**, 민트는 남성 이벤트 가능성 |
| 팀 인원 | 각 팀 7명 (5+2) | 주인공 여성 선수 **6명** (출전 5, 교체 정책 상세 미결) |
| 선수 개성 | 기본 공통 수치 중심 | 얼굴, 선수별 특성·성장·스킬 구상 |
| 도파민 | 없음 | 마나, 스킬 소비/충전 설계 예정 |
| 이벤트 | 없음 | 특별 장비전/미끄럼전 등의 아이디어 검토 |
