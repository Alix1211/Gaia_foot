| 가이아식 이름 | 스탯 | 풋살 기능 |

**확정 범위:** 6개 이름과 풋살 경기에서의 기능. 정확한 수치, 성장식, 캐릭터별 분배는 미확정이다.

- 친밀도는 기본 스탯에서 제외하며, 추후 관계 변수로 사용할 수 있다.
- 도파민은 스킬 마나다.
- 현재 체력 게이지는 STAMINA의 영향을 받는 실시간 자원이다.

## 변경 규칙

- 사용자가 어떤 결정을 **최종 확정**하면 해당 행의 상태를 바꾸고 날짜·대화 내용·커밋을 `WORKLOG.md`에 연결.
- 사용자가 마음을 바꾸면 이전 결정을 조용히 덮어쓰지 말고 **'변경 전 → 변경 후'**를 이 문서와 작업일지에 기록.
- AI의 제안은 승인되기 전까지 원칙적으로 계속 **제안**이다.
- 사용자가 하지 않겠다고 한 **구체적 에셋/연출만** 비채택 처리. 아이디어 전체를 영구 금지로 확대하지 않는다.
